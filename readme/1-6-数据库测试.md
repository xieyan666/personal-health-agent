# 6. 发现并修复的问题

首次运行发现两个测试代码问题：

- AuditLog 用例在失败事务 rollback 后访问已过期 ORM 对象的 id，引发异步 `MissingGreenlet`。修正为在失败事务前保存纯 UUID，再用该 UUID 查询 AuditLog。
- TimestampMixin 用例最初位于统一外层 rollback transaction 中。PostgreSQL `now()` 在同一事务内保持事务开始时间，无法验证跨事务更新时间变化。修正为使用独立 AsyncSession 进行两次真实 commit，并在 finally 中删除测试用户。
- pytest-asyncio 提示 fixture loop scope 将改变默认值，已在 `pytest.ini` 明确设置为 function。

以上均为测试实现和测试配置问题。没有发现需要修改 Model、Constraint 或 Migration 的明确错误。
